# Theme

## Compact token summary
- Canvas `#F5F2EA`; surface `#FFFFFF`; elevated `#FCFAF6`.
- Ink `#17212B`; muted `#52606D`; subtle `#798897`.
- Action `#075CCB`; action hover `#0548A1`; action wash `#EBF3FC`.
- Success `#176B45`; warning `#8A4B00`; stale `#92400E`; error `#A12622`.
- Display: Manrope 500–800. Body: Atkinson Hyperlegible 400/700. Mono: system monospace.
- Spacing: 4, 8, 12, 16, 20, 24, 32, 40, 48px.
- Radius: 4, 8, 12, 16px. Shadows are restrained neutral elevation.
- Minimum interactive target: 44×44px. Focus: 3px action outline with 3px offset.
- High-contrast tokens switch to near-black surfaces, white ink and cyan actions.

## Raw source
Complete tokens: `src/ui/styles/tokens.css`

Complete global styles: `src/ui/styles/index.css`

No Tailwind configuration is used; styling is vanilla CSS plus targeted React style objects.
